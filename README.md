# AUTUMN DRIVE

A standalone browser driving prototype inspired by the uploaded video reference.

## Important separation

This is a completely separate project from LOWTOWN.
It has its own source tree, visual direction, documentation, and future GitHub repository.

## Current prototype

- Canvas-based browser driving scene
- Third-person road view
- Wet reflective asphalt
- Warm autumn environment
- Cool overcast sky
- Velocity-based motion blur
- Keyboard controls: W/S or Up/Down for speed, A/D or Left/Right for steering
- Camera follows the actual vehicle travel direction

## Run

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.


Pages deployment trigger verified on main.
